# E-Commerce Sales Dashboard – Power BI

## Project Overview

This Power BI dashboard analyzes e-commerce sales data to provide insights into sales, profit, quantity, orders, customers, payment methods, states, and product performance.

## Tools Used

* Power BI
* Power Query
* DAX
* Excel / CSV

## Key KPIs

* Total Amount
* Total Profit
* Total Quantity
* Total Orders

## Dashboard Features

* Sales analysis by state
* Quantity analysis by category
* Monthly profit analysis
* Sales analysis by customer
* Payment mode analysis
* Profit analysis by sub-category
* Quarter and state slicers
* Interactive dashboard filtering

## Key Insights

* Identified high-performing states based on sales.
* Compared quantity contribution across product categories.
* Analyzed monthly profit trends.
* Compared payment methods based on quantity.
* Identified profitable product sub-categories.
